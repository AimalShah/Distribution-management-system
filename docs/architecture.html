What is DistroManager?

DistroManager is a comprehensive Distribution Management System built to manage the complete business operations of distribution companies. It handles the full lifecycle from procurement (purchases from suppliers) through inventory management to sales (invoices to customers), with full tracking, reporting, and multi-organization support.

The system is designed as a multi-tenant SaaS application where each organization has isolated data, role-based access control, and complete operational autonomy.

Core Business Value: Streamlines distribution operations by unifying procurement, inventory, sales, and reporting into a single platform with real-time stock tracking and comprehensive analytics.

Role-Based Access Control (RBAC)

RolePermissionsScope
Owner Full access: create, update, delete all resources. Manage members, invitations, and organization settings. Organization
Admin Create and update resources. Cannot delete or manage organization settings. Organization
Member Create-only access. Can create records but cannot update or delete existing ones. Organization

Auth Configuration

export const auth = betterAuth({ database: prismaAdapter(prisma, { provider: "postgresql" }), emailAndPassword: { enabled: true, autoSignIn: true }, plugins: [ organization({ organizationLimit: 5, // Max orgs per user roles: { owner, adminRole, member } }), admin({ defaultRole: "admin" }) ] });
Session Management: Each session stores activeOrganizationId to maintain organization context. Users can switch between organizations via the sidebar dropdown, and all data queries are scoped to the active organization.

// Adjustment sets absolute quantity case "ADJUSTMENT": newQty = data.quantity; // Set to exact value // Return adds back to stock case "RETURN": newQty = previousQty + data.quantity; // Damaged/Expired removes from stock case "DAMAGED": case "EXPIRED": newQty = previousQty - data.quantity;

🛡 API Layer

Next.js Server Actions as the primary API layer

All data mutations and queries are handled through Next.js Server Actions, providing a type-safe, direct frontend-to-database communication channel without traditional REST API overhead.

The auth API route handles all authentication endpoints:

  • /api/auth/sign-in - Email/password login
  • /api/auth/sign-up - User registration
  • /api/auth/sign-out - Logout
  • /api/auth/verify-email - Email verification
  • /api/auth/organization/create - Create organization
  • /api/auth/organization/set-active - Switch organization
  • /api/auth/invite - Invite members
