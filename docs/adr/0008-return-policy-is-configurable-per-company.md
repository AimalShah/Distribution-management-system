# Return policy is configurable per Company

Returns are governed by rules held per Company: a **return window** (default 30 days) measured from the original invoice, a requirement that a sale return **reference its original invoice**, and a **condition gate** (every returned line is marked restockable or damaged, with a reason). Partial returns are allowed up to the unreturned quantity. Sale returns settle as store credit (ADR 0006); there is no cash-refund path.

**Consequences:** a return outside the window, or against an unknown invoice, is refused by the server, not merely hidden in the UI.

**Status:** accepted
