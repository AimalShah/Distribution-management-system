# Sale returns settle as store credit, not cash

A sale return credits the customer's ledger (reducing balance due) instead of issuing a cash refund. The ledger already derives what a customer owes from invoices minus returns minus payments, so store credit needs no cash-drawer machinery and is exactly reversible. Damaged or expired returned stock is credited at its returnable value.

**Consequences:** a customer who wants cash must be settled outside the return flow.

**Status:** accepted
